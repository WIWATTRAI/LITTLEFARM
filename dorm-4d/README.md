# หอพักอาคาร A – หน้าดูโมเดล 3D ตามวันที่แผนงาน (4D)

`index.html` เปิดในเบราว์เซอร์ได้ทันที (โหลด Three.js 0.160.0 จาก cdn.jsdelivr.net จึงต้องต่ออินเทอร์เน็ต)

- แถบเลื่อนวันที่ตั้งแต่วันเริ่มแผน 9 พ.ย. 2569 ถึงวันสุดท้ายของแผน และปุ่ม ▶ เล่น เดินทีละวัน
- ชิ้นส่วนแสดงเมื่อถึงวันเริ่มกิจกรรมที่ผูกไว้ ระหว่างทำแสดงเป็นสีส้ม พ้นวันเสร็จแล้วแสดงเป็นสีตามหมวดงาน
- ชิ้นส่วนที่ task = `DONE` (งานที่เสร็จก่อนวันเริ่มแผน) แสดงตลอด
- กล่องซ้ายบนแสดงกิจกรรมที่ทำในวันที่เลือก และจำนวนชิ้นส่วนในโมเดลของแต่ละกิจกรรม

## ข้อมูล
`data/elements.json` และ `data/schedule.json` คัดลอกจากชุดข้อมูลโมเดล SketchUp หอพัก (`/mnt/project-files/dorm-4d/`)
แผนงานมาจาก Gantt Chart หอพักชัยเสรี อาคาร A R3

สร้าง `index.html` ใหม่หลังข้อมูลเปลี่ยน:

```
python3 build.py              # ใช้ ./data
python3 build.py <โฟลเดอร์>   # ใช้ elements.json + schedule.json จากโฟลเดอร์อื่น
```

`viewer.html` คือแม่แบบหน้า (ไม่มีข้อมูล) ส่วน `build.py` ฝังข้อมูลลงไปเป็น `index.html`
