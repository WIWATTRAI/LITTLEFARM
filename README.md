# LITTLEFARM Games

เปิด `index.html` ในเบราว์เซอร์ (มือถือหรือคอม) ไม่ต้องติดตั้งอะไร

## สาวน้อยแสงกับแมวส้ม (`dragon/`)
เกมแพลตฟอร์ม 3 ด่าน: สาวน้อยผมบ๊อบเดินเก็บผลไม้ ยิงลำแสงใส่ลูกมังกร และปราบบอสมังกรท้ายด่าน
แมวส้มเป็นเพื่อนคอยตะปบมังกรอัตโนมัติ และมี "พลังแมว" พุ่งโจมตีทั้งจอเมื่อเกจเต็ม (เติมจากผลไม้/ล้มมังกร)

| ด่าน | ฉาก | บอส |
|---|---|---|
| 1 | ทุ่งผลไม้ | มังกรเขียว |
| 2 | ป่าสนธยา (ลูกมังกรพ่นไฟ) | มังกรม่วง |
| 3 | ภูเขาไฟมังกร (ฝนไฟ) | ราชามังกรไฟ |

- มือถือ: ปุ่ม ◀ ▶ เดิน · โดด · แสง (กดค้างยิงต่อเนื่อง) · แมว — เล่นได้ทั้งแนวนอนและแนวตั้ง
- คอม: ← → เดิน · ↑/Space กระโดด · J ยิงแสง · K พลังแมว · P หยุด
- ด่านที่ปลดล็อกแล้วจะถูกจำไว้ในเบราว์เซอร์

## Neon Ellipse Bounce (`ellipse/`)
ไข่แก้วทรงรีสามมิติ (spheroid) เรนเดอร์ด้วย three.js (WebGL): แก้วหักเหแสง ลูกบอลผิวมันเงา เงาบนพื้น จุดโฟกัสเรืองแสง ลูกบอลที่ปล่อยจากจุดโฟกัสล่าง สะท้อนผนังแล้ววิ่งผ่านโฟกัสบนเสมอ (ต้องต่ออินเทอร์เน็ตเพื่อโหลด three.js)

- ลากเพื่อหมุนมุมมอง · บีบนิ้ว/ล้อเมาส์เพื่อซูม · แตะเพื่อยิงลูก · ปุ่ม "มุมมอง" สลับมุมเอียง / ด้านข้าง / มองจากบน
- ลูกบอลโตขึ้นตามอายุ (ปรับด้วยแถบ "โตเร็ว" หรือปิดด้วยปุ่ม "โตตามอายุ")
- "ชนกันได้": เมื่อสองลูกชนกัน ลูกที่อายุมากกว่าจะหายไป (นับใน `popped`)
