# Neon Ellipse Bounce

เกมกราฟิกลูกบอลนีออนเด้งในวงรี (แนว "Will they all hit the same point?")

ลูกบอลทุกลูกถูกปล่อยจาก **จุดโฟกัสล่าง** ของวงรี ไม่ว่าจะยิงไปทิศไหน
เมื่อสะท้อนผนังวงรีแล้วจะวิ่งผ่าน **จุดโฟกัสบน** เสมอ (สมบัติการสะท้อนของวงรี)

## วิธีเล่น
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

- แตะ/คลิกในวงรี — ยิงลูกบอลจากโฟกัสล่างไปทางนั้น
- ปล่อยจากโฟกัส / ปล่อยจากจุดสุ่ม — เปรียบเทียบว่าถ้าไม่เริ่มที่โฟกัส ลูกจะไม่มาบรรจบกัน
- +1 / +10 ลูก, เพิ่มอัตโนมัติ, เปิด/ปิดเส้นทาง, เสียง, ความเร็ว, เริ่มใหม่
- `hits` นับจำนวนครั้งที่ลูกบอลวิ่งผ่านโฟกัสบน
