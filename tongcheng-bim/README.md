# BIM 3D/4D – อาคารโกดังและงานบริเวณ บริษัท ตงเฉิน อีเล็คทริค เคเบิ้ล แอนด์ไวร์ (WEC-TC-6901)

แบบจำลอง BIM ระดับ LOD 200–300 ใช้ทวนสอบ BOQ และวางแผนลำดับงานสำหรับการเสนอราคา

## ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวดูโมเดล 3D/4D เปิดในเบราว์เซอร์ได้ทันที มีชั้นข้อมูล ตัดระดับ คลิกดูข้อมูลชิ้นส่วน แถบเวลา 4D ตารางทวนสอบ BOQ แผนงาน และ QTO |
| `out/TC-WH_BIM.ifc` | IFC4 เปิดได้ใน Revit, Navisworks, Solibri, BIMcollab Zoom, BlenderBIM มี IfcWorkSchedule/IfcTask 37 กิจกรรม และ `Pset_TC_BOQ_4D` ในทุกชิ้นส่วน (WBS, BOQ_Item, TaskID, PlannedStart/Finish, ปริมาตร, น้ำหนักเหล็ก) |
| `out/TC-WH_BIM_QTO.xlsx` | ชีต 1-ทวนสอบ BOQ, 2-QTO จากโมเดล, 3-แผนงาน 4D, 4-สถานการณ์ดินถม |
| `model.py` | นิยามโมเดลทั้งหมด (กริด ระดับ ชิ้นส่วน แผนงาน CPM) เป็นแหล่งข้อมูลเดียว |
| `build.py` | สร้าง IFC, Excel, JSON และ `index.html` ใหม่: `pip install ifcopenshell openpyxl` แล้วรัน `python3 build.py` |

## สมมติฐานหลัก (ต้องยืนยัน)
- ระดับดินเดิม = ระดับถนนอ้างอิง -1.50 (รอผลสำรวจระดับ P1.2) จึงได้ดินถม ~8,566 ลบ.ม.
- เข็มทุกต้นยาว 22 ม. ตาม Type Mark (รอผลเจาะสำรวจดิน P3)
- หน้าตัดโครงถัก แป ค้ำยัน คานชั้นลอย และผนังก่อถึง +4.50 เป็นค่าสมมติ เพราะยังไม่มีแบบโครงหลังคาและแบบสถาปัตย์
- ตำแหน่งเข็มถนน (I22-22) วางตามระยะ 3 ม. รอบอาคาร ตำแหน่งเข็มถังใต้ดิน หม้อแปลง และอาคารประกอบเป็นค่าประมาณจากผัง
- แนวเขตที่ดินวัดจากผัง A101 (±0.5 ม.)
- ปฏิทินงาน: จันทร์–เสาร์ หักวันหยุดราชการ เริ่มนับจากวันยื่นราคา Preconstruction 5 พ.ย. 2569

ใน Navisworks TimeLiner ให้ใช้ Auto-Attach ด้วยกฎ property `Pset_TC_BOQ_4D.TaskID` เพื่อผูกชิ้นส่วนกับกิจกรรม
